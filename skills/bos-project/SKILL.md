# Project (BOS)

> Draft generated by `bos skills draft` from `docs/glossary/project.md` and the core's `project` model.
> Grow it by hand: it is never overwritten.

## What it is

One concrete, independent project with its own name and a focused workflow,
set up to be a project repository.

## Where

Inside a [scope](scope.md): `forge/<scope>/<project>`.

## Handling

- `bos flow explain` / `bos flow next <branch>`: the project's craft loop (`.github/bos.json`) and a branch's forward step
- `bos devlog state`: where the project stands (phases of `docs/devlog/TODO.md`, open questions, waiting orders)
- `bos project describe [--skryba]`: a conventional-commit draft of what is staged
- `bos project authors [--dryRun]`: `.github/AUTHORS` kept up to date
- `bos project install-hooks`: its git hooks report to the workshop's storylines

Every project carries the standard anatomy (`README.md`, `LICENSE`, `AGENTS.md` +
`CLAUDE.md`, `Taskfile.yml`, `src/`, `docs/`, `tests/`, `.github/`); `bos workshop status`
reports what is missing.
