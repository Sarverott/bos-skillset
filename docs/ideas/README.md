# Ideas

What the skillset could become, kept as words until it is built. None of it is
code here: the skillset is skills, manifests and docs, and every behaviour of
BOS lives in the core, the npm package
[`blacksmith-organization-system`](https://github.com/Sarverott/blacksmith-organization-system).
When an idea is taken up, it is built in the core (or in a new package of the
scope), and the skillset only points at it.

| Page | The idea |
| ---- | -------- |
| [agent suit](agent-suit.md) | what an agent could get beyond skills: MCP tools, a session brief, slash commands, its work recorded in storylines |
| [procedures](procedures.md) | routines the suit had as code: opening and closing the workshop, commit drafts by Skryba, git hooks into storylines, the House's registry, drafting skills |
| [packaging](packaging.md) | how a plugin with code could install with nothing but Node, and be released |

History: a first build of all of this existed on `development` (commit `dea1cf5`,
`git show dea1cf5 --stat`). It was removed to start again from a clean
skillset; the code is still there in git history.
