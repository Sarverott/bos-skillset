# Vision

BOS skills should let people and AI agents work comfortably in the same
workshop, with a shared vocabulary, discoverable procedures and clear records
of what is decided, implemented and still open.

The core owns executable BOS behaviour. This skillset makes it usable through
portable instructions, agent adapters and maintained documentation. Taskfiles
provide approachable entrypoints; dependency management should make those
entrypoints reproducible without duplicating the core.

Adopt concepts in small, verified steps: meaning, core capability, skill,
packaging, then a realistic usage check. Keep owner dialogue, agents' findings
and release history in their respective places. Preserve unresolved meanings.

This direction comes from Sett's 2026-11-06 request to synthesize the assembled
contributor guides and reference manuals into a usable local guide.
