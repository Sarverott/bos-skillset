# Opening Protocol

related to all models - requires stuff to be closed first, it is being done after bootup

Steps: the core bootstraps the workshop (`bos workshop bootstrap`: missing areas
and descriptors, never overwriting) → the agents' guides (`AGENTS.md`,
`CLAUDE.md` from `resources/workshop-root/`) are put in the workshop root when
missing → the opening is recorded in `.BOS/storylines/logs/workshop.jsonl`.
