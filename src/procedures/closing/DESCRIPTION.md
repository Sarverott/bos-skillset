# Closing Protocol

related to all models - requires stuff to be open first, it is being done before shutdown

Steps: copy the shell history (`$HISTFILE` or `~/.bash_history`) to
`.BOS/storylines/ttystories/ttystory-<host>-<unixusat>.txt` → record the closing
in `.BOS/storylines/logs/workshop.jsonl`. Shell history can hold secrets: treat
ttystories like `.BOS/setup`.
